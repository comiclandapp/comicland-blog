<p>Version 3.0 brought some real quality-of-life upgrades under the hood, several of which are still shaping how ComicLand feels today.</p>
<h2>Keeping up with iOS 12</h2>
<p>A handful of small adjustments kept ComicLand running well on iOS 12.</p>
<h2>Face recognition for thumbnails</h2>
<p>An optional feature let ComicLand use face recognition to automatically crop creator and character thumbnails — no more hand-cropping every headshot.</p>
<h2>Fuzzy search</h2>
<p>Searching titles and names started tolerating typos and near-matches, so a small spelling mistake no longer meant zero results.</p>
<h2>Faster lists and grids</h2>
<p>Lists and grids began prefetching upcoming rows, so scrolling felt noticeably smoother.</p>
<h2>A real rich text editor</h2>
<p>Descriptions and notes got a new WYSIWYG editor, complete with a source view and syntax highlighting.</p>
