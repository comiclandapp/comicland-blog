The native Mac app has moved well beyond a window that can open a collection. The current development build is becoming a practical desktop cataloguing workspace, with the same collection concepts as iOS and controls suited to a keyboard, pointer and larger display.

## Browse visually, catalogue in a table

Comics can be browsed as cover tiles or lists, or in a configurable table. Table columns can be hidden and reordered, and selection feeds the existing bulk actions. Filters and saved Smart Lists let you return to useful views instead of rebuilding the same search each time.

The sidebar keeps Comics, Series, Publishers, Creators and Characters close to Statistics and Database tools. Following a related publisher or creator opens that entity, rather than losing its context in a generic list.

## The desktop details matter

The editors cover the main entities and their relationships, and records can be created, duplicated, merged or deleted through the appropriate actions. Country flags on series, publisher and creator rows, plus status and priority badges on comics, make the browser easier to read at a glance.

Picker action menus now offer named-item creation where it is supported, and multi-select pickers can clear their selection before applying it. Retailer suggestions draw on the built-in list used by iOS as well as the current library’s shops.

## One collection model

The Mac app uses the shared domain and persistence rules rather than a separate desktop interpretation of the data. The design reference remains the same: Book Tracker’s continuity across devices, and Apple Music’s efficient desktop library interaction.

It opens a user-owned `.comiclandlibrary` package and can import supported iOS backups. Account/sync and provider integration remain deferred on Mac. The focus is making local cataloguing comfortable and dependable before declaring the desktop app finished.
